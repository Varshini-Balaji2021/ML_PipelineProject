Feature Engineering Governance

  1. EDA proposes features; it does not automatically approve all of them.
  2. Deterministic ratios may be executed when mathematical rules are valid.
  3. Domain features require subject-matter approval.
  4. Statistical and interaction features remain hypotheses.
  5. ML transformations must be fitted on training data only.
  6. Inferential features must satisfy interpretation and estimability requirements.
  7. The test set must never determine feature creation or selection.
